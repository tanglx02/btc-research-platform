================================================================
  BTC 全市场智能研究平台 —— Windows 便携版
================================================================

【这是什么】
    一个自带 Python 运行环境的绿色版。
    不需要安装 Python，不需要联网装依赖，解压即可运行。


----------------------------------------------------------------
  三步开始
----------------------------------------------------------------

  1. 解压
     把整个压缩包解压到任意目录。
     建议路径不要太深，也不要含中文以外的特殊字符。
     例如：  D:\BTC平台\
     注意：必须整个解压，不能只挑几个文件夹 —— runtime\ 里有 5000 多个
     文件，缺一个都跑不起来。

  2. 启动
     双击  【一键启动.bat】

     - 之后会弹出浏览器打开 http://127.0.0.1:8000
     - 第一次打开会进入【安装引导页】（见下一节）
     - 看到命令行窗口里出现 "Application startup complete" 就是成功了
     - 这个黑色窗口不能关，关了服务就停了

  3. 停止
     直接关闭那个黑色命令行窗口，或者双击【停止.bat】

  说明：命令行窗口里的提示是英文的，这是刻意的 ——
        批处理文件里放中文，在不同版本的 cmd 上有概率乱码甚至把命令带崩，
        所以中文说明都放在本文件里。


----------------------------------------------------------------
  第一次启动：选数据库（安装引导）
----------------------------------------------------------------

  第一次打开网页会进入安装引导页，分三步：

    步骤 1  选数据库类型
            SQLite       单机、零配置，数据就在本机一个文件里
            PostgreSQL   推荐给"多台设备共用同一份数据"的场景
            MySQL        团队已有 MySQL 时用这个

    步骤 2  填连接参数
            SQLite  只需要填一个文件路径
            其它    填主机 / 端口 / 数据库名 / 用户名 / 口令
            （也可以点"高级"直接粘贴完整连接串）

    步骤 3  点【测试连接】，然后【保存并完成】

  自检会做 5 项检查，每一项都要变绿才能保存：
    1) 连接串格式对不对
    2) 异步驱动装没装（便携版已内置 asyncpg / aiomysql）
    3) 能不能连上（会回显数据库版本）
    4) 这个库里有没有平台的表
    5) 有没有建表/删表的权限

  任何一项红了，下面都会直接给出该查什么（口令错？端口没开？库不存在？
  缺权限？），照着做即可。**自检没通过时不会把连接串写进配置**，
  不会出现"配错了还被锁在系统外面"的情况。

  想让多台设备数据一致：把 PostgreSQL / MySQL 装在一台大家都能访问的
  机器上，每台设备的引导页都指向同一个库即可。

  已经装好了想换数据库：
      在此目录打开命令行，执行
        runtime\python.exe app\scripts\btcctl.py setup-reset
      下次打开网页会重新进入引导页。这个操作只改标记，不删任何数据。

  想先验证一下连接串通不通（不用开网页）：
        runtime\python.exe app\scripts\btcctl.py db-test --url "postgresql+asyncpg://btc:口令@10.0.0.5:5432/btc"


----------------------------------------------------------------
  第一次使用必看：数据是空的
----------------------------------------------------------------

  便携版不带任何历史数据。完成安装引导后需要自己拉取：

    方式一：双击【采集历史数据.bat】
            会拉取最近 730 天（约两年）的 K 线

    方式二：命令行方式（可选）
            在此目录打开命令行，执行：
              runtime\python.exe app\scripts\btcctl.py backfill --days 730
              runtime\python.exe app\scripts\btcctl.py collect-all

  说明：
    - 必须先完成安装引导，否则采集命令会报"尚未安装"
    - backfill 支持断点续传，中途中断了重新执行会接着上次的进度
    - collect-all 是拉链上、衍生品、情绪、宏观、ETF 等数据
    - 默认用 SQLite 时，数据全部存在本地 app\data\btc.db，
      删除此文件即清空；用 PostgreSQL / MySQL 时数据在那个库里


----------------------------------------------------------------
  常见问题
----------------------------------------------------------------

  Q：双击 .bat 后冒出一堆
     "'xxx' 不是内部或外部命令，也不是可运行的程序"，
     最后报 [ERROR] Bundled Python runtime not found？
  A：这是批处理文件的换行符坏了（cmd.exe 要求 CRLF，
     如果是 LF 它会把相邻行粘成一坨来解析）。
     本压缩包里的脚本已修正为 CRLF，正常情况下不会再出现。
     如果仍出现，多半是解压不完整 —— 请完整重新解压，
     尤其是 runtime\ 目录。

  Q：有些数据源显示"未配置"？
  A：Glassnode、CryptoQuant、Coinglass 这类需要 API Key。
     在网页「系统设置」页填写即可，保存即生效，不用重启。
     平台不会用假数据假装正常。

  Q：国内网络很多源连不上？
  A：两条路都试试：
     1）在「系统设置」配置代理（支持 SOCKS5 / SOCKS4 / HTTP / HTTPS，
        可全局也可单源）
     2）把「DNS 解析方式」改成 DoH
     先用这个接口确认是不是 DNS 污染（浏览器打开即可）：
        http://127.0.0.1:8000/api/v1/system/dns/diagnose?host=api.binance.com

  Q：「测试代理连通性」到底是谁在发请求？
  A：是运行这个平台的那台**服务器**在发，不是你的浏览器。
     测试结果里会显示发起方的主机名、进程 PID 和内网 IP，
     可以和你自己的电脑对比确认。你浏览器挂的代理不影响这个结果。

  Q：想换端口？
  A：用记事本打开【一键启动.bat】，把开头的 set "PORT=8000" 改成别的数字。
     注意【停止.bat】里的 PORT 要同步改成同一个值。

  Q：数据怎么备份？
  A：用 SQLite 时，把 app\data\btc.db 复制走即可，整个系统的状态都在里面。
     用 PostgreSQL / MySQL 时用数据库自己的备份工具
     （pg_dump / mysqldump）。

  Q：能拷到另一台电脑继续用吗？
  A：可以。整个文件夹直接拷走，或者只拷 app\data\btc.db 到新的便携版里
     （限 SQLite）。如果两台电脑要共用同一份数据，请改用 PostgreSQL /
     MySQL，别用拷文件的方式 —— 那只会得到两份各自漂移的数据。


----------------------------------------------------------------
  目录说明
----------------------------------------------------------------

  runtime\      自带的 Python 3.13.15 运行环境 + 全部依赖包
                （含 asyncpg / aiomysql，所以三种数据库开箱可用）
                不要删除或修改这里的内容

  app\          平台源码
      backend\      后端 Python 代码
      frontend\     前端页面
      scripts\      运维命令行脚本
      docs\         37 份设计文档
      data\         数据库（首次运行自动生成）
      logs\         运行日志（自动生成）

  一键启动.bat      启动
  停止.bat          停止
  采集历史数据.bat   拉取历史行情
