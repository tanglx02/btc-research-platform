# 05 交叉验证与数据置信度

一句话定位：同一指标有多个来源时，系统如何判断「信谁」，以及当来源不够或互相矛盾时如何**如实降级**而不是硬凑一个数。

## 代码位置

| 文件 | 职责 |
| --- | --- |
| `backend/app/providers/validation.py` | `cross_validate()`、`sanity_check_price()`、`completeness_ratio()` |
| `backend/app/providers/types.py` | `QualityStatus` 枚举 |
| `backend/app/providers/router.py` | `fetch_validated()`：取主源 + 并发取其他源做交叉验证 |

## 置信度状态（QualityStatus）

定义在 `types.py`，**必须由 API 与前端显式呈现，不允许隐藏**：

| 状态 | 含义 |
| --- | --- |
| `VERIFIED` | 2 个及以上来源交叉验证通过 |
| `CROSS_VERIFIED` | 3 个及以上来源交叉验证通过（置信度更高） |
| `SINGLE_SOURCE` | 仅单一数据源可得，置信度下调 |
| `ESTIMATED` | 发生降级/推导，需降置信度 |
| `STALE` | 已是最近一次可信数据（当前取不到新数据） |
| `CONFLICT` | 多源不一致 |
| `MISSING` | 明确无数据（**绝不伪造**） |
| `NOT_CONFIGURED` | 数据源未配置 |

## 交叉验证判定逻辑

`cross_validate(values, tolerance_pct, min_sources)`：

```
1. 过滤掉 None / 非有限值
2. 无有效值           → NO_DATA / MISSING
3. 有效来源 < min_sources → SINGLE_SOURCE（置信度下调，但不报错）
4. 最大偏差 > 容差     → CONFLICT（记录冲突，前端必须提示）
5. 否则               → 来源 ≥3 为 CROSS_VERIFIED，否则 VERIFIED
```

统计口径：

| 量 | 计算 |
| --- | --- |
| median | `statistics.median` |
| mean | `statistics.fmean` |
| `max_deviation_pct` | `max(|v - median| / median × 100)` |
| `spread_pct` | `(max - min) / median × 100` |

## 关键配置

| 配置项 | 默认值 | 含义 |
| --- | --- | --- |
| `CROSS_VALIDATION_TOLERANCE_PCT` | 0.35 | 价格交叉验证容差（%） |
| `CROSS_VALIDATION_MIN_SOURCES` | 2 | 达到几源才算交叉验证通过 |

## 健全性检查（防污染历史）

`sanity_check_price(price, reference)`：与参考值偏差 **> 25%** 时直接拒绝，返回 `False` 与原因「与参考值偏差过大，拒绝写入以免污染历史数据」。

这是防止单个异常源把坏数据写进历史库的重要闸门。

## 完整度

`completeness_ratio(expected, actual)` 计算字段完整度，参与健康评分的 `completeness` 维度（权重 0.15）。

## 降级原则

| 情况 | 行为 |
| --- | --- |
| 所有源都取不到新数据 | 返回**最后一次可信数据**并标记 `STALE`，前端必须显示「降级运行」 |
| 来源不足 | 标记 `SINGLE_SOURCE`，不报错 |
| 来源互相矛盾 | 标记 `CONFLICT`，取中位数并在页面提示「仅供参考」 |
| 明确无数据 | 返回 `MISSING`，**绝不生成估计值** |

## 在智能监测中的应用

预警模块复用这套状态作为「数据质量门槛」：

| 规则字段 | 作用 |
| --- | --- |
| `min_quality` | 低于该等级的数据不参与判定 |
| `require_fresh` | 数据必须在时效内且不得是 `STALE` |
| `require_multi_source` | 必须 ≥2 个独立数据源确认 |

等级序：`ANY < MISSING < STALE < SINGLE_SOURCE < VERIFIED < CROSS_VERIFIED`。

详见 `31-智能监测与条件预警.md`。
