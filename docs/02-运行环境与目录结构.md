# 02 运行环境与目录结构

一句话定位：本项目如何跑起来、目录里每个文件夹负责什么、数据落在哪里。

## 运行环境要求

| 项 | 要求 |
| --- | --- |
| Python | 3.13（项目 venv 实测 3.13.12） |
| Node | **非必需**。仅在做前端语法检查（`node --check`）时才用；平台本身零构建 |
| 数据库 | SQLite 开箱即用；生产可选 PostgreSQL + TimescaleDB |
| 操作系统 | Windows 10/11、Linux（均已提供一键脚本） |
| 网络 | 需能访问数据源；国内环境建议配置 SOCKS5/HTTP 代理 |

## 依赖安装

```bash
pip install -r requirements.txt
# 国内加速
pip install -r requirements.txt -i https://mirrors.cloud.tencent.com/pypi/simple
```

关键依赖：`fastapi`、`uvicorn[standard]`、`SQLAlchemy[asyncio]`、`aiosqlite`、`httpx`、`httpx-socks`、`numpy`、`pandas`、`APScheduler`。

## 启动方式

### Windows

```
scripts\windows\install.bat    # 安装依赖
scripts\windows\start.bat      # 启动
scripts\windows\status.bat     # 查看状态
scripts\windows\stop.bat       # 停止
```

### Linux

```bash
bash scripts/linux/install.sh
bash scripts/linux/start.sh
bash scripts/linux/status.sh
bash scripts/linux/stop.sh
```

### 直接启动

```bash
uvicorn app.main:app --host 127.0.0.1 --port 8000 --app-dir backend
```

启动后访问 `http://127.0.0.1:8000`。

## 配置文件

复制 `.env.example` 为 `.env` 后修改。主要分组：

| 分组 | 关键项 |
| --- | --- |
| 基础 | `HOST`、`PORT`、`ENV`、`DB_PATH`、`API_PREFIX=/api/v1` |
| 调度 | `SCHEDULER_ENABLED`、`JOB_*_SECONDS`（共 15 个任务） |
| 健康与切换 | `FAILURE_THRESHOLD=3`、`RECOVERY_SUCCESS_STREAK=3`、`RECOVERY_COOLDOWN_SECONDS=180` |
| 交叉验证 | `CROSS_VALIDATION_TOLERANCE_PCT=0.35`、`CROSS_VALIDATION_MIN_SOURCES=2` |
| 数据源 Key | `GLASSNODE_API_KEY`、`COINGLASS_API_KEY`、`FRED_API_KEY`、`CRYPTOQUANT_API_KEY` |
| AI 助手 | `AI_ASSISTANT_ENABLED`、`OPENAI_API_KEY`、`OPENAI_BASE_URL`、`OPENAI_MODEL` |
| 智能监测 | `ALERTS_ENABLED`、`JOB_ALERT_*`、`ALERT_DIGEST_*`、`SMTP_*`、`PUBLIC_BASE_URL` |
| CORS | `CORS_ORIGINS`（生产请写显式来源） |
