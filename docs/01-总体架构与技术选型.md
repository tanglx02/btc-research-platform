# 01 总体架构与技术选型

一句话定位：一个可长期运行、多数据源高可用、结论可追溯的 BTC 全市场智能研究平台，Windows 与 Linux 双平台部署。

## 一句话架构

```
外部数据源（27 个 Provider）
    ↓  ResilientRouter（主备切换 + 熔断 + 恢复）
采集与存储（Raw + Normalized 双写，幂等）
    ↓
引擎层（指标 / 周期 / 估值 / 风险 / 综合状态 / 预测）
    ↓
服务层（行情 / 回测 / 回放 / 策略 / 资金计划 / 智能监测）
    ↓
API（FastAPI，/api/v1）  ──→  零构建前端 SPA
    ↓
Scheduler（单一调度器，15 个任务）
```

## 技术选型

| 层 | 选型 | 理由 |
| --- | --- | --- |
| Web 框架 | FastAPI | 原生 async，自带 OpenAPI，Pydantic 校验 |
| 运行时 | Uvicorn | ASGI，支持热重载 |
| ORM | SQLAlchemy 2.0 async | 统一异步接口，SQLite / PostgreSQL 可切换 |
| 数据库 | SQLite(aiosqlite) 开箱；PostgreSQL + TimescaleDB 可选 | 个人部署零依赖；生产可平滑升级 |
| 网络 | httpx + httpx-socks | 支持 HTTP/HTTPS/**SOCKS5 代理**（国内网络必需） |
| 计算 | numpy + pandas | 指标与回测向量化 |
| 调度 | APScheduler | 成熟稳定，支持 cron 与 interval |
| 前端 | 原生 HTML/JS + 本地化 ECharts | **零构建**，不需要 Node/npm |
| 配置 | pydantic-settings + `.env` | 类型安全，默认值明确 |
| 日志 | 结构化单行 JSON | 便于检索与审计 |
| 测试 | pytest + pytest-asyncio | 异步用例一等公民 |

依赖清单见 `requirements.txt`（含国内镜像安装说明）。

## 分层职责

| 层 | 目录 | 职责 | 禁止 |
| --- | --- | --- | --- |
| Provider | `app/providers/` | 对接外部数据源；健康评分；主备切换；交叉验证 | 业务层不得直接发 HTTP |
| 采集 | `app/collectors/` | 历史回填、增量同步、缺口补洞 | 不得绕过 Provider 层 |
| 存储 | `app/db/` | Raw + Normalized 双写、幂等、迁移 | 不得伪造数据 |
| 引擎 | `app/engines/` | 指标 / 周期 / 估值 / 风险 / Regime / 预测 | 不得使用未来数据 |
| 服务 | `app/services/` | 行情、回测、回放、策略、资金计划 | 不直接碰 transport |
| 智能监测 | `app/alerts/` | 条件规则引擎、状态机、通知、回测 | 不自建数据源与调度 |
| API | `app/api/` | HTTP 接口、鉴权、错误处理 | 不写业务逻辑 |
| 前端 | `frontend/` | 渲染、可追溯展示 | 不含指标计算 |
| 调度 | `app/scheduler/` | 统一任务编排 | 只允许一个调度器 |

## 核心设计原则

| 原则 | 落地 |
| --- | --- |
| 多数据源高可用 | 27 个 Provider，主源 + 备用 1~5，健康评分自动切换 |
| 绝不伪造数据 | 无数据返回 `MISSING`，降级返回 `STALE` 并**显式标注**，前端必须展示 |
| 结论可追溯 | 浏览器上任何数字都能展开到原始 JSON（`raw_market_data`） |
| 防未来数据泄漏 | 回测 / 回放 / 预测 / 预警回测四路统一因果切片，见 `18-防未来数据泄漏规范.md` |
| 本地历史优先 | 读历史先查库，够用不再请求外部 |
| 幂等与断点续传 | Raw + Normalized 双写，`sync_checkpoints` 记录进度，支持补洞 |
| 增量最小侵入 | 新功能追加模块，不重写既有系统 |

## 运行形态

- **单进程**：Uvicorn 起 FastAPI，内部启动 APScheduler。
- **单用户本地部署**：写接口用 `X-Admin-Token` 保护，无多租户。
- **跨平台**：Windows 用 `scripts/windows/*.bat`（11 个），Linux 用 `scripts/linux/*.sh`（11 个）。
