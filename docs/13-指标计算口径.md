# 13 指标计算口径

一句话定位：用本地 `candles` 表的日线数据，纯 numpy 计算一套确定性技术指标，实盘展示与历史回放共用同一份实现。

## 代码位置

| 文件 | 作用 |
| --- | --- |
| `backend/app/engines/indicators.py` | 全部指标函数与 `IndicatorEngine` 入口 |
| `backend/app/services/market_service.py` （`indicators()`，约 122-136 行） | 读取本地 K 线后调用 `IndicatorEngine.compute()`，附加 `source` 块 |
| `backend/app/services/replay_service.py` （96-99 行） | 回放场景下用截断后的 K 线调用同一引擎 |
| `backend/app/db/repo.py` （`latest_candles()`） | 提供按时间升序的 K 线数组（先倒序取 N 根再 `reverse()`） |
| `backend/app/db/model_registry.py` （`ind_v1` 档案） | 该引擎的模型版本登记 |

## 实现口径

### 基础函数（`indicators.py`）

| 函数 | 默认参数 | 计算口径 |
| --- | --- | --- |
| `sma(values, window)` | 无默认；调用处用 20 / 50 / 200 | 前缀和滑动平均；样本数 `< window` 时整段返回 `nan` |
| `ema(values, span)` | 调用处用 50，MACD 用 12/26/9 | 递归 `out[i] = α·x[i] + (1-α)·out[i-1]`，`α = 2/(span+1)`；**首值直接取 `values[0]`** |
| `rsi(values, period=14)` | 14 | Wilder 平滑：`avg = (prev·(period-1) + 当前)/period`；`avg_loss == 0 且 avg_gain > 0` 时置 100 |
| `macd(values, fast=12, slow=26, signal=9)` | 12 / 26 / 9 | 返回 `(line, signal, hist)`，`hist = line - signal` |
| `true_range(high, low, close)` | — | `max(high-low, |high-prev_close|, |low-prev_close|)`，首根 K 线用自身 close 作 prev |
| `atr(high, low, close, period=14)` | 14 | 对 TR 做 **EMA(span=14)**，不是 Wilder RMA |
| `bollinger(values, window=20, k=2.0)` | 20 / 2.0 | 中轨 = SMA20；标准差为**总体标准差**（`np.std`，ddof=0） |
| `realized_volatility(close, window=30, annualize=365)` | 30 / 365 | `std(对数收益) × sqrt(365) × 100`，输出百分比；加密市场按 365 个交易日年化 |
| `max_drawdown(close)` | — | 返回 `(最大回撤%, 峰值索引, 谷底索引)`，基于全样本 `maximum.accumulate` |
| `drawdown_series(close)` | — | 逐点 `(close - 历史峰值)/历史峰值 × 100` |
| `percentile_of(value, series)` | — | `(series <= value).sum() / len × 100`，**含等号** |
| `vwap(high, low, close, volume)` | — | 典型价 × 成交量累计 ÷ 累计成交量，从传入窗口首根开始累计，**不按日/会话重置** |
| `pct_change(values, periods)` | 调用处 1/7/30/90/365 | `(last - last[-(p+1)]) / base × 100`；base 为 0 时返回 `nan` |

### `IndicatorEngine.compute(candles, include_series=True)`

- 类常量：`VERSION = "ind_v1"`；模块常量 `MIN_BARS_NEEDED = 210`。
- 输入必须是按时间升序的标准化 K 线 dict（`ts/open/high/low/close/volume`）；空输入返回 `{"latest": {}, "series": {}, "meta": {"bars": 0}, "version": ...}`。
- `latest` 输出字段（`indicators.py` 193-232 行）：

| 字段 | 说明 |
| --- | --- |
| `price` | 最后一根收盘价 |
| `ma20 / ma50 / ma200 / ema50` | 均线；样本不足为 `None` |
| `rsi14` | 14 日 RSI |
| `macd / macd_signal / macd_hist` | MACD 三件套 |
| `atr14 / atr_pct` | ATR 与 `ATR/收盘价 × 100` |
| `bb_upper / bb_mid / bb_lower` | 布林带 |
| `volatility_30d` | 30 日年化波动率（%） |
| `vwap` | 累计 VWAP |
| `drawdown / max_drawdown` | 当前回撤（%）与全样本最大回撤（%） |
| `change_24h / 7d / 30d / 90d / 365d` | 由 `pct_change(close, 1/7/30/90/365)` 得出 |
| `price_percentile / rsi_percentile / volatility_percentile` | 用传入的完整序列自算历史分位 |
| `ath / distance_to_ath / atl / distance_to_atl` | 历史最高、最低及距其百分比 |

- `series` 输出（仅 `include_series=True`）：`ma20 / ma50 / ma200 / rsi14 / macd / macd_signal / macd_hist / atr14 / volatility_30d / drawdown / price`，格式为 `[ts, 值]` 列表，`nan`/`inf` 点直接跳过。
- `meta`：`bars`、`start_ts`、`end_ts`、`max_drawdown_window{peak_ts, trough_ts}`。
- 数值出口统一走内部 `last()`：非有限值一律转成 `None`，不会把 `nan` 传给前端。

## 与其它模块的关系

- `market_service.indicators()` 是唯一线上入口，读取本地 `limit=500` 根日线；`market_service.analysis()` 把 `latest` 喂给估值/周期/风险引擎。
- `replay_service.replay()` 传入**已按回放日截断**的 K 线，因此同一引擎在回放里算出的分位、ATH、均线都是「当时可见」的。
- `backtest_service._simulate()` 不调用本引擎，而是在循环里自行重算 `ath / percentile / ma200`，以保证逐日推进（见文档 18）。
- 指标字典（`IndicatorDefinition` 表，API `GET /research/indicators/dictionary`）为这些指标提供通俗解释与 `requires_paid_provider` 标记。

## 已知局限 / 注意事项

1. **付费数据源**：本引擎只依赖本地 `candles` 表，本身不需要任何 API Key；但链上类指标（如 MVRV）来自付费 Provider（`GLASSNODE_API_KEY` / `CRYPTOQUANT_API_KEY`，见 `backend/app/core/config.py`），未配置时不写入库、估值侧会在 `missing_factors` 中声明缺失，**系统不会用估算值或假数据顶替**。
2. `atr()` 使用 EMA 平滑而非 Wilder RMA，与主流行情软件的 ATR14 数值会有偏差，字段名 `atr14` 容易被误解为标准 ATR。
3. `realized_volatility()` 与 `bollinger()` 用总体标准差（ddof=0），与部分平台（用样本标准差）不可直接对齐。
4. `vwap` 从传入窗口第一根累计，窗口越长越接近「全历史均价」，不是日内 VWAP；前端不应把它当日内成本线展示。
5. `change_24h` 实际是「最近 1 根 K 线」的涨跌幅。当前调用方只传 `1d` 周期，语义成立；若将来传入其它 interval，字段名会与实际不符。
6. `ema()` 首个值取 `values[0]`，短序列下 EMA 存在初始化偏差（序列越长影响越小）。
7. `max_drawdown` 是**传入样本内**的最大回撤，不是「自持仓以来」的回撤；回测场景的回撤由 `backtest_service` 单独计算。
8. `MIN_BARS_NEEDED = 210` 已定义但在全仓库中**没有被任何代码引用**（死常量），样本不足的实际表现由各函数自行返回 `nan/None`。
9. 分位数（`price_percentile` 等）在实盘场景用全量历史计算——这属于「当前时刻可见信息」而非未来函数；但在回放/回测中必须传入截断序列才成立。
10. 当前**未提供**盘中（分钟级）指标、成交量加权类衍生指标（OBV、资金流指标）以及指标写库任务：`IndicatorEngine` 有 `series` 输出与 `indicator_values` 表的设计意图，但本文件内没有任何写库代码。
